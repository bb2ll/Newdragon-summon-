# 后端联机说明

## 启动方式

在 `D:\VMABCD\gongxiang\01\dungeon-mercenary-unified` 打开命令窗口，运行：

`node serve-static.js`

然后打开：

`http://localhost:4177`

## 已完成的联机功能

| 功能 | 地址 | 说明 |
| --- | --- | --- |
| 健康检查 | `GET /api/health` | 判断后端是否启动 |
| 英雄等级排行榜 | `GET /api/leaderboard` | 读取排行榜和切磋记录 |
| 上传英雄 | `POST /api/leaderboard` | 把本地英雄上传到排行榜 |
| 好友切磋 | `POST /api/arena/challenge` | 用本地英雄挑战排行榜英雄 |
| 世界 Boss | `GET /api/world-boss` | 读取深渊古龙血量 |
| 攻击世界 Boss | `POST /api/world-boss/attack` | 多名佣兵共同造成伤害并获得奖励 |

## 数据保存

后端数据保存在：

`data/server-state.json`

当前实现是本地联机测试版，适合一台机器或局域网小范围验证。正式上线时可以把这里替换成 MongoDB。

## 检查方式

服务启动后运行：

`npm run test:online`

它会检查：

- 后端是否启动
- 英雄是否能上传排行榜
- 排行榜是否能读回上传英雄
- 好友切磋是否能返回胜负
- 世界 Boss 是否会扣血
