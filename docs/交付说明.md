1. 在该目录打开命令窗口
2. 运行 `node serve-static.js`
3. 浏览器打开 `http://localhost:4177`

## 已绑定的玩法模块

- 控制中心：资源总览、快速招募、快速战斗、迷宫进度。
- 佣兵管理：招募、职业展示、属性展示、详情面板、升级。
- 工作派遣：给佣兵安排工作，领取碎金收益。
- 数据迷宫：选择佣兵挑战不同难度，生成战斗记录和奖励。
- 赛博之龙：终局 Boss 挑战，记录挑战结果。
- 互动区：联机排行榜、上传战绩、好友切磋、挑战记录。
- 世界 Boss：后端保存血量，多个英雄可共同造成伤害。
- 游戏设置：音量、动效、自动保存、重置存档。
